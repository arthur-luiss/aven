# Aven

Site institucional one-page da Aven, empresa de criação de sites, landing pages e otimizações técnicas.

## Stack

- TanStack Start (React 19, Vite, TypeScript)
- Tailwind CSS v4 (configurado em `src/styles.css`)
- lucide-react para ícones
- Vitest para testes

## Como rodar

    npm install
    npm run dev

## Scripts

- `npm run dev`: servidor de desenvolvimento
- `npm run build`: build de produção
- `npm run test`: testes
- `npm run lint`: lint
